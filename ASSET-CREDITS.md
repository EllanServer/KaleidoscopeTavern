## Changes made by this rewrite

This Paper / CraftEngine rewrite has modified and adapted the original assets.
Changes include reorganizing the Forge resource tree into a CraftEngine
resource pack, generating item and block model references, splitting models
into state and furniture variants, adjusting model rotations, pivots, UVs and
display transforms, and adapting HUD graphics for the server-provided resource
pack. Git history records the detailed changes.

These changes are not endorsed by the original authors. The adapted artistic
resources remain under CC BY-NC-SA 4.0 and must retain this attribution and
license when shared.
